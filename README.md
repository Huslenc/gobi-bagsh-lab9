### Гол дүгнэлт

Branch хамралт 100% байхад энэ алдаа харагдахгүй байсан, учир нь `score > 60` ба `score >= 60` хоёр ижил true/false салаануудыг үүсгэдэг. Аль ч тохиолдолд 65 (true) ба 30 (false) оноо хоёр салааг дайрна. Хамралт нь "салаа бүр ядаж нэг удаа ажилласан уу" гэдгийг хэмждэг, харин нөхцөл зөв утгатай харьцуулж байгаа эсэхийг хэмждэггүй. Зөвхөн яг 60 оноог шалгасан тест хоёр хувилбарын ялгааг илрүүлнэ. Иймд хамралт нь тестээ хөтлөх хэрэгсэл боловч кодыг зөв гэдгийг батлах хангалттай нотолгоо биш.
